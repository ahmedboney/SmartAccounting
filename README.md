# نظام المحاسبة المتكامل — لوجه الله

نظام محاسبة عربي متكامل (رسمي للمكاتب المحاسبية ومكاتب إدارة الميزانية)، مجاني 100% لوجه الله.

## المميزات
- دليل حسابات + شجرة حسابات
- دفتر قيود اليومية (مسودة / ترحيل / تسوية / افتتاحي / إقفال)
- الأستاذ العام + ميزان المراجعة
- موازنة تقديرية ومقارنتها بالمصروف الفعلي
- مناطق / فروع منفصلة (مركز رئيسي، أقاليم...)
- صلاحيات: مدير / محاسب / مشاهدة فقط
- تصدير Excel رسمي (أسود Bold + حدود + توقيعات قابلة للتعديل)
- نسخ احتياطية تلقائية شهرية + استيراد من Excel
- سجل عمليات + حماية من تكرار القيود
- قاعدة بيانات SQLite — لا تحتاج تركيب

## التشغيل
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح `http://localhost:5000`

دخول تجريبي:
`admin / admin123` (مدير) — `ahmed / ahmed123` (محاسب) — `viewer / viewer123` (مشاهدة)

> ⚠️ غيّر كلمات المرور من الإعدادات فور أول استخدام.

## النسخة الجاهزة
من ملف `نظام المحاسبة - نسخة التشغيل.zip` — نسخة EXE تعمل بدون تركيب.

صُنع لوجه الله — ادعوا لصانعه بالخير 🤍
